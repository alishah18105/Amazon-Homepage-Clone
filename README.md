## 📌 Amazon Homepage Clone

A static and responsive replica of the **Amazon homepage**, created to practice modern front-end web development using clean HTML structure and CSS styling techniques.

## 🚀 Features

* 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile screens
* 🎨 **Modern CSS Layouts** – Built using Flexbox and best CSS practices
* 🧩 **Clean & Semantic HTML** – Structured for readability and accessibility
* ⚡ **Lightweight Project** – Pure HTML and CSS, no frameworks used
